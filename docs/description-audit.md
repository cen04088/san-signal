# 산 소개 전수조사 (2026-11-09)

대상은 `public/data/mountains.json`의 138개 산입니다. 상세 화면 '산 소개'에 나오는 두 글을 봤습니다.

- 선정사유(`top`): 산림청 산정보 서비스의 100대 명산 선정 사유. 굵은 글씨로 먼저 나옵니다.
- 산 소개(`description`): 산정보 서비스의 산 설명. 없으면 올라 데이터의 설명을 씁니다.

방법은 두 가지입니다. 스크립트로 깨진 글자, 잘림, 빈 값을 셌고, 138개 글을 세 묶음으로 나눠 전부 읽었습니다. 심각도 '높음'은 원문과 다시 대조했습니다.

## 조치 결과 (같은 날 반영)

- 빌드(`scripts/build_mountains.py`, `scripts/descriptions.py`)에서 엔티티를 풀고, `( - )`·공백·"위치 명산." 대체 문구를 버리고, 따옴표·전각 문자·괄호 한자를 정리합니다. 글은 끝난 문장까지만 남깁니다.
- 후보 글(지자체별 산정보 레코드와 올라 설명) 중 이 산 이름이 들어 있는 글을 고릅니다. 팔공산, 도봉산, 대둔산, 비슬산, 민주지산, 금정산, 청량산, 유명산이 이 방식으로 제대로 된 글을 갖게 됐습니다.
- 산별 수정은 `scripts/description_fixes.json`에 있습니다 (문장 삭제와 오탈자 교정, 84개 산). 다시 빌드해도 유지됩니다.
- 다른 산 설명이거나 고칠 수 없는 글은 비웠습니다: 천성산, 영축산, 무갑산, 황학산, 병풍산, 봉황산. 소개가 없는 산은 모두 21개이고, 화면에서 '산 소개' 칸이 숨겨집니다.
- 선정사유는 화면과 데이터에서 뺐습니다.
- 올라 설명을 쓴 10개 산은 출처를 '이전 프로젝트(올라)에서 정리한 자료'로 표시합니다.
- 산 데이터: 높이 4곳(덕유산 1,614m, 예봉산 683m, 축령산 886m, 산방산 395m), 이름 3곳(청량산, 가야산, 황장산), 지역 5곳(달음산 부산 기장군, 방장산 고창·장성·정읍, 제암산 장흥·보성, 삼봉산 함양·남원, 유명산 가평·양평)을 고쳤고, 국립공원 구역 표시 11곳(도봉산, 남덕유산, 대야산, 도락산, 금수산, 황장산, 입암산, 팔영산, 노인봉, 점봉산, 제비봉)을 더했습니다. 지역 문자열 '전남 보성군·장흥군'처럼 뒤쪽 시도가 빠진 표기를 읽지 못하던 문제도 고쳐 수리산(군포·안산), 가야산(예산), 학가산(예천)에 빠졌던 지역이 들어갔습니다.
- 확인하지 못해 그대로 둔 것: 구병산·계방산·금정산의 국립공원 여부, 신불산(1,209m / 산정보 1,159m)·가칠봉·황학산 높이.

## 6. 선정사유 (전체)

67개 모두 "~점 등을 고려(감안)하여 선정, ~이 유명"으로 끝나는 메모체입니다. 43개는 160자에서 잘려 "…"로 끝나고, 13개는 "선정" 뒤에 다른 필드가 붙어 있습니다. 태백산, 무등산, 팔공산은 "도립공원으로 지정"이라고 적혀 화면의 국립공원 표시와 어긋납니다. '국보 제○호' 같은 지정번호 표기도 2024년에 없어진 방식입니다.

선정사유는 화면에서 빼는 것을 권합니다. 남긴다면 "100대 명산 선정 사유"라는 이름을 붙이고 첫 구절("~점 등을 고려하여 선정")까지만 보여줘야 합니다.

## 7. 소개문과 별개인 산 데이터 오류

소개문을 읽다가 발견한, 앱 자체 데이터(`mountains.json`, 올라 산 목록에서 가져옴)의 문제입니다.

- 높이
  - 덕유산 1,507m: 최고봉 향적봉은 1,614m입니다. 1,507m는 남덕유산 높이입니다.
  - 예봉산 638m: 본문과 일반 자료 모두 683m입니다. 숫자가 뒤바뀐 것으로 보입니다.
  - 축령산(남양주) 622m: 장성 축령산 높이로 보입니다. 남양주 축령산은 약 886m입니다.
- 이름: '봉화청량산', '서산가야산', '문경황장산'이 목록과 상세 화면에 그대로 나옵니다. 화면에는 '청량산'처럼 쓰고 지역으로 구분하는 편이 자연스럽습니다. 산정보 검색도 이 이름으로 해서 실패했습니다.
- 국립공원 표시가 빠졌을 수 있는 산 (확인 필요): 도봉산(북한산), 남덕유산(덕유산), 대야산·구병산(속리산), 금수산·도락산·문경황장산(월악산), 입암산(내장산), 팔영산(2011년 다도해해상국립공원 편입)
- 지역 확인 필요: 달음산(부산 기장군으로 알려짐, 앱은 경남 양산시), 방장산(고창·장성 경계로 알려짐), 제암산(장흥 누락), 삼봉산
- 무등산 지역 '전남 동구'는 2026년 전남광주통합특별시 출범을 반영한 것이라 오류가 아닙니다.

## 고치는 순서 제안

1. 빌드 스크립트 일괄 처리 (`scripts/build_mountains.py`). 원문을 바꾸지 않는 기계적 정리입니다.
   - `html.unescape`로 엔티티를 풀고 줄바꿈은 공백으로 바꿉니다.
   - `( - )`, 공백만 있는 값, "위치 명산." 대체 문구는 빈 값으로 둡니다. 빈 값이면 '산 소개' 칸이 숨겨집니다.
   - 이름이 정확히 같은 기록이 없으면 첫 번째 검색 결과를 쓰지 않습니다.
   - 자를 때는 마지막으로 끝난 문장까지만 남기고, 끝난 문장이 없으면 버립니다.
   - 따옴표와 전각 문자를 통일하고 괄호 한자를 지웁니다.
   - 선정사유는 화면에서 뺍니다.
2. 산별 손질. 위 1, 3, 4, 5번 표대로 원문 문장을 지우거나 오탈자만 고칩니다. 새 내용은 쓰지 않습니다.
3. 산 데이터 오류 수정. 높이 3곳과 이름 3곳을 고치고, 국립공원 표시는 확인 후 고칩니다.
4. 재매칭. 비었거나 지운 산 약 25곳은 산정보 API를 정확한 이름과 지역으로 다시 찾아야 합니다. 공공데이터포털 인증키가 있어야 합니다.
