## 활용 내용
산불위험예보·산사태예측·산악기상은 시군구나 관측소 단위로 제공되어, 등산객이 "내가 갈 산"의 상황을 알려면
여러 사이트를 오가며 직접 해석해야 합니다. 산행 신호등은 이 데이터를 **산 단위로 다시 묶어**
전국 138개 산의 산행 안전을 🟢좋음 · 🟡주의 · 🔴위험 신호등으로 보여줍니다.

- 산이 걸친 시군구의 산불위험지수와 산사태 주의보·경보, 가까운 산악기상관측소의 실측 기온·풍속·강수로 판정
- 판정 근거를 문장과 출처로 함께 표시 (예: "바람이 강해요 8.4m/s — 산림청 산악기상")
- 해 지는 시각과 일반 코스 소요 시간으로 "늦어도 몇 시까지 출발" 안내
- 산림청 등산로 공간정보로 산별 등산로 지도를 그리고, 위험구간(암벽·절벽 등 3,278구간)과 폐쇄구간을 강조
- 서버 없이 GitHub Actions가 매시간 데이터를 모아 정적 사이트로 배포 → 운영비 0원, 심사 기간에도 계속 동작

## 효과
- 등산 전 확인할 산림 재난·기상 정보 3종을 **한 화면, 한 번의 판단**으로 줄임
- 시군구·관측소 단위 데이터를 산 단위로 이어 붙이는 매칭 방법(산-시군구 138/138, 산-관측소 137/138, 산-등산로 119/138)을 공개해 다른 활용자가 재사용 가능
- 일몰 전 하산 시각 안내로 조난 원인(일몰 후 하산)을 미리 줄이도록 유도

## 화면·결과물 캡처 (제출용으로 찍을 것)
1. 첫 화면: 전국 지도 + 좋음/주의/위험 집계 (PC)
2. 위험·주의 산 상세: 신호등 + 근거 문장 + 4칸 요약
3. 북한산 상세: 등산로 지도에 위험구간(주황) 표시
4. 휴대폰 화면 1~2장

## 개선 아이디어
README의 "만들면서 발견한 데이터 개선 의견" 8개 항목을 그대로 옮기되, 수치를 꼭 넣기:
1. 산악기상정보 `tm` 미지정 시 전 관측소 값이 `-` → 기본값·문서 개선
2. 산악기상 관측소 좌표·고도 미제공 → 메타데이터 제공
3. 산정보 서비스 좌표·통합 산 ID 부재 (동명이산, 지자체별 산코드)
4. 등산로 기준일 2016-12-31(99.9%), 난이도 '쉬움' 98.4%, 깨진 값 21건, 통제 Y 11건
5. 등산로 150MB SHP 단일 제공 → 산별 GeoJSON·API
6. 산사태예측 '현재 발령 중' 조회 불가, 빈 예보명 의미 불명
7. 기관별 행정구역 표기 불일치 → 시군구 코드 병기
8. 공공데이터포털 API CORS 미허용
