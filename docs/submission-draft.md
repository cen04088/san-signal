## 활용 내용
산불위험예보, 산사태예측, 산악기상은 시군구나 관측소 단위로 제공됩니다. 그래서 등산객이 "내가 갈 산"의 상황을 알려면
여러 사이트를 오가며 직접 해석해야 합니다. 산행 신호등은 이 데이터를 산 단위로 다시 묶어
전국 138개 산의 산행 안전을 좋음·주의·위험 신호등으로 보여줍니다.

- 산이 걸친 시군구의 산불위험지수와 산사태 주의보·경보, 가까운 산악기상관측소의 기온·풍속·강수로 판정합니다.
- 판정 근거를 문장과 출처로 함께 보여줍니다. 예: "바람이 강해요 (8.4m/s), 산림청 산악기상"
- 해 지는 시각과 일반 코스 소요 시간으로 늦어도 몇 시까지 출발해야 하는지 알려줍니다.
- 산림청 등산로 공간정보로 산별 등산로 지도를 그리고, 위험구간(암벽·절벽 등 3,278구간)과 폐쇄구간을 다른 색으로 표시합니다.
- 휴대폰에서는 지도를 화면 전체에 두고 목록을 아래 시트에 담아, 지도와 판정을 한 화면에서 함께 봅니다. 다크 모드와 움직임 줄이기 설정을 따릅니다.
- 서버 없이 GitHub Actions가 매시간 데이터를 모아 정적 사이트로 배포합니다. 운영비가 0원이고 심사 기간에도 매시간 갱신됩니다.

## 효과
- 등산 전에 세 곳에서 따로 확인하던 산불위험, 산사태, 산악기상을 산 이름 하나로 한 화면에서 확인합니다.
- 시군구·관측소 단위 데이터를 산 단위로 잇는 방법과 결과(산과 시군구 138/138, 산과 관측소 137/138, 산과 등산로 119/138)를 공개해 다른 활용자가 다시 쓸 수 있습니다.
- 일몰 전 하산 시각을 미리 알려 일몰 뒤 하산으로 생기는 조난을 줄이도록 돕습니다.

## 화면 캡처 (제출용으로 찍을 것)
1. 첫 화면: 전국 지도와 좋음·주의·위험 집계 (PC)
2. 위험·주의 산 상세: 신호등, 근거 문장, 4칸 요약
3. 북한산 상세: 등산로 지도에 위험구간(주황) 표시
4. 휴대폰 화면 1~2장 (시트를 중간 높이로 올린 상태)

## 개선 아이디어
README의 "만들면서 발견한 데이터 개선 의견" 8개 항목을 수치와 함께 옮깁니다.
1. 산악기상정보는 `tm`을 넣지 않으면 모든 관측소 값이 `-`로 옵니다. 기본값과 문서를 고쳐 주세요.
2. 산악기상 관측소의 좌표와 고도가 없습니다. 관측소 메타데이터를 제공해 주세요.
3. 산정보 서비스에 좌표와 통합 산 ID가 없습니다 (동명이산, 지자체별 산코드).
4. 등산로 기준일의 99.9%가 2016-12-31이고, 난이도 '쉬움'이 98.4%, 깨진 값 21건, 통제 Y 11건입니다.
5. 등산로가 150MB SHP 한 파일로만 제공됩니다. 산별 GeoJSON이나 API를 제안합니다.
6. 산사태예측에서 지금 발령 중인 주의보·경보를 조회할 수 없고, 빈 예보명의 의미가 문서에 없습니다.
7. 데이터마다 행정구역 표기가 다릅니다. 시군구 코드를 함께 주세요.
8. 공공데이터포털 API가 CORS를 허용하지 않습니다.
