# 산행 신호등 🚦⛰️

> **오늘, 이 산 가도 될까?**
> 산림청 공공데이터 5종을 묶어 전국 138개 산의 산행 안전을 🟢🟡🔴 신호등으로 알려주는 웹 서비스

- 서비스 주소: **https://cen04088.github.io/san-signal/**
- 산 하나를 바로 열기: `https://cen04088.github.io/san-signal/#m004` (북한산)

## 무엇을 하나요

등산 전에 확인해야 할 산림 재난·기상 정보는 산불위험예보, 산사태정보, 산악기상 사이트에 흩어져 있고,
대부분 **시군구·관측소 단위**라서 "내가 갈 산"과 바로 이어지지 않습니다.
산행 신호등은 이 데이터를 **산 단위로 다시 묶어** 한 화면에서 판단을 내려줍니다.

| 화면 | 내용 |
|---|---|
| 전국 지도·목록 | 138개 산을 신호 색으로 표시, 위험한 산부터 정렬, 검색·국립공원·내 주변 필터 |
| 산 상세 | 신호등 + **왜 그런지**(근거 문장과 출처), 산불·산사태·산악기상·해 지는 시각 4칸 요약 |
| 등산로 지도 | 산림청 등산로 구간을 지도에 표시, **위험구간·폐쇄구간** 강조, 구간별 소요 시간 |
| 산 소개 | 산림청 산정보 서비스의 산 설명·선정 사유 |

## 활용한 산림청 공공데이터

| # | 데이터명 | 방식 | 이 서비스에서 쓰는 곳 |
|---|---|---|---|
| 1 | 산림청 국립산림과학원_산불위험예보정보 (시군구) | API, 매시간 | 산이 걸친 시군구의 산불위험지수(평균·최고) → 단계 판정 |
| 2 | 산림청_산사태예측정보 | API, 매시간 | 최근 3시간 내 산사태 주의보·경보 발령 여부 |
| 3 | 산림청 국립산림과학원_산악기상정보 | API, 매시간 | 산악기상관측소 513곳 실측 기온·풍속·습도·강수 → 체감온도·강풍·강수 판정 |
| 4 | 산림청_산정보 서비스 | API, 1회 수집 | 산코드, 소재지 주소(시군구 매칭), 산 소개 |
| 5 | 산림청 등산로(1:25,000) 공간정보 (SHP) | 파일, 1회 가공 | 57,449개 등산로 구간 → 산별 등산로 지도·위험구간·폐쇄구간 |

산 목록(138개 산의 좌표·고도·일반 코스 소요 시간)은 이전 프로젝트에서 정리한 자료를 가져왔고,
일출·일몰 시각은 외부 API 없이 브라우저에서 계산합니다.

## 동작 구조 — 서버 없이 0원으로 운영

```
GitHub Actions (매시 7분)
  └─ scripts/fetch_live.py ── 산불위험예보·산사태예측·산악기상 API 호출
        └─ public/live/snapshot.json (약 45KB)
  └─ vite build → GitHub Pages 배포

브라우저
  └─ mountains.json(산 138개) + snapshot.json + trails/<산>.json 을 읽어 직접 판정
```

- 공공데이터포털 API는 브라우저에서 직접 부를 수 없어서(CORS) 수집은 Actions가 맡고, 화면은 정적 파일만 읽습니다.
- 한 API가 실패하면 직전 값을 '지연' 표시와 함께 이어서 씁니다. 데이터가 3시간 넘게 오래되면 화면 상단에 알려줍니다.
- 인증키는 GitHub Secrets(`PUBLIC_SERVICE_KEY`)에만 있고 저장소·화면에는 노출되지 않습니다.

## 판정 기준

점수를 합산하지 않고 **가장 나쁜 신호를 따릅니다.** 하나라도 🔴이면 🔴입니다.

| 항목 | 🟡 주의 | 🔴 위험 | 근거 |
|---|---|---|---|
| 산불위험지수 (시군구 평균) | 66 이상 (높음) | 86 이상 (매우높음) | 산림청 산불위험예보 단계 |
| 산사태 | 주의보 | 경보 | 산림청 산사태예측 |
| 풍속 (10m) | 8 m/s 이상 | 14 m/s 이상 | 기상청 강풍주의보 기준 준용 |
| 강수 | 비 관측 | 10 mm 이상 | |
| 체감온도 | −10℃ 이하 | −25℃ 이하 | 기상청 겨울철 체감온도식·단계 |
| 기온 | 33℃ 이상 | 35℃ 이상 | 폭염특보 기준 준용 |
| 일몰 | 지금 출발하면 일몰 전 하산이 빠듯함 (코스 시간+30분) | 일몰 30분 전 이내 | |

해가 진 시간에는 일몰 항목을 빼고, 화면에 "야간 산행은 피하세요"와 다음 일출 시각을 보여줍니다.

### 산과 데이터 잇기

| 연결 | 방법 | 결과 |
|---|---|---|
| 산 → 시군구 (산불·산사태) | 산 소재지 + 여러 시군구에 걸친 산은 직접 지정 | 138/138 |
| 산 → 산악기상관측소 | 관측소 이름(`양평 용문산`)의 시군·산 이름으로 매칭 → 없으면 같은 시군구 관측소 → 없으면 가장 가까운 산의 관측소 | 이름 일치 24 · 같은 시군구 104 · 인근 9 · 없음 1 |
| 산 → 등산로 | 산코드 일치(20km 이내) 또는 산 이름 일치(12km 이내, 동명이산 방지) | 119/138 |

같은 시군구에 관측소가 여러 곳이면 기온·습도는 평균, 바람·비는 중앙값을 쓰고, 한 곳이라도 강풍·강한 비가 있으면 🟡로 알립니다.

## 만들면서 발견한 데이터 개선 의견

실제로 서비스를 만들며 부딪힌 문제를 수치와 함께 정리했습니다. (`scripts/` 실행 로그 기준, 2026-11-09)

1. **산악기상정보: 관측시각(`tm`)을 넣지 않으면 513개 관측소의 모든 값이 `-`로 옵니다.**
   `tm`을 넣으면 501곳이 정상 응답합니다. 기본값을 '최근 관측'으로 하거나 문서에 필수값으로 명시해 주세요.
2. **산악기상정보: 관측소 좌표·해발고도가 응답에 없습니다.**
   관측소 이름 문자열로만 산과 이어야 해서, 138개 산 중 이름으로 바로 이어지는 곳은 24곳뿐입니다. 관측소 메타데이터(위경도·고도·소재 시군구 코드) 제공을 제안합니다.
3. **산정보 서비스: 좌표가 없고 같은 이름의 산을 구분하기 어렵습니다.**
   '지리산'으로 검색하면 안동·통영의 다른 지리산이 함께 나오고, 한 산(북한산)도 지자체마다 다른 산코드(114100801, 113050202)를 씁니다. 산 단위 통합 ID와 대표 좌표가 있으면 다른 데이터와 바로 이을 수 있습니다.
4. **등산로 공간정보: 57,449개 구간 중 99.9%의 기준일이 2016-12-31입니다.**
   난이도는 98.4%가 '쉬움'이고, `어려리구`·`어려동구`처럼 깨진 값도 21건 있습니다. 통제 여부 'Y'는 11건뿐이라 현재 통제 상황을 반영하지 못합니다. 갱신 주기와 난이도 기준을 정비하고, 실시간 통제 정보와 연계해 주세요.
5. **등산로 원본이 약 150MB SHP(UTM-K) 한 덩어리입니다.**
   웹·앱에서 쓰려면 직접 좌표 변환·분할을 해야 합니다(이 서비스는 산별 JSON 약 1MB로 줄여 씀). 산별 GeoJSON 파일이나 산코드로 조회하는 API가 있으면 활용 장벽이 크게 낮아집니다.
6. **산사태예측정보: '지금 발령 중'을 바로 조회할 수 없습니다.**
   22,729건의 발령 이력을 최신순으로 넘기며 계산해야 하고, 예보명(`lndslFrcstNm`)이 빈 레코드의 의미(해제? 미발령?)가 문서에 없습니다. 현재 발령 현황 엔드포인트와 필드 정의를 제안합니다.
7. **기관·데이터마다 행정구역 표기가 다르고 코드가 없습니다.**
   산불위험예보는 `전남광주통합특별시`, 산사태예측은 `경상북도 안동시` 문자열, 산정보는 `서울특별시  강북구`(공백 2칸)처럼 제각각입니다. 법정동(시군구) 코드를 함께 주면 데이터끼리 바로 이을 수 있습니다.
8. **공공데이터포털 API가 CORS를 허용하지 않아** 브라우저만으로는 서비스를 만들 수 없습니다. 인증이 필요 없는 공개 데이터는 CORS 허용이나 주기적 정적 파일(JSON) 제공을 제안합니다.

## 직접 실행하기

```bash
npm install
# 실시간 스냅샷 만들기 (공공데이터포털 일반 인증키, Encoding 값)
PUBLIC_SERVICE_KEY=발급키 python scripts/fetch_live.py
npm run dev
```

산 목록·등산로를 다시 만들 때만:

```bash
PUBLIC_SERVICE_KEY=발급키 python scripts/build_mountains.py <올라 저장소>/backend/recommendations/mountain_data.py
python scripts/build_trails.py <WG_MT_WAY SHP 폴더>
```
